## ✨ Features

### Core Features
- 📄 **Resume Upload** - Support PDF and DOCX files
- 📝 **Job Description Input** - Paste or type job requirements
- 🎯 **ATS Score Calculation** - 0-100% compatibility score
- 🔑 **Keyword Extraction** - Identify matched and missing keywords
- 💡 **Smart Suggestions** - Actionable improvement tips
- 📊 **Visual Analytics** - Progress bars and score visualization

### Advanced Features
- 🤖 **ML-Powered Analysis** - TF-IDF vectorization + Cosine Similarity
- 🔍 **Skills Extraction** - Automatic skill detection from resumes
- 📈 **Real-time Analysis** - Instant results with loading animations
- 🌓 **Dark/Light Mode** - Toggle between themes
- 📱 **Responsive Design** - Works on all devices
- 🔒 **Free to Use** - No login required
